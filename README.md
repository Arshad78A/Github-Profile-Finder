
# 🔍 GitHub Profile Finder

A fast, beautiful GitHub profile explorer. Search any username and see profile stats, top languages, total stars, and repositories — inspired by GitHub's own UI.

![preview]

**Live Demo:** https://arshad78a.github.io/Github-Profile-Finder/
**Typing Tester Live:** https://arshad78a.github.io/Typing-speed-tester/

--

### ✨ Features

- 🔎 Search any GitHub username (`torvalds`, `github`, `arshad78a`)
- 👤 Profile card - avatar, bio, location, company, blog, join date
- 📊 Stats - Public repos, followers, following, **total stars earned**
- 🎨 Language breakdown - Top languages with GitHub colors & % bar
- 📚 Repositories grid - Latest 10 repos with description, language, stars, forks
- ↕️ Sort repos by **Updated** / **Stars**
- 🟩 Contribution heatmap style activity graph
- 🌗 Dark / Light mode (saved in localStorage)
- 🕘 Recent searches
- ⚠️ Handles 404 (user not found) & rate limit errors
- 📱 Fully responsive

### 🛠️ Tech Stack

- HTML5
- CSS3 (Custom properties for theming)
- Vanilla JavaScript (ES6+ Fetch API)
- GitHub REST API v3 (No auth, 60 req/hour)
- No frameworks
